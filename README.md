# 🌴 Sistema Atlantis - Protótipo Web

Protótipo Front-end (SPA) para o **Sistema Atlantis**, um software de gestão para hotéis, pousadas e resorts. Esta versão substitui a antiga interface de terminal (CLI) por uma interface gráfica moderna e responsiva.

## ✨ Funcionalidades Principais

O protótipo opera com **dados simulados em memória** para validação visual e de fluxo (UI/UX), contemplando:

* **Autenticação:** Tela de login inicial (simulada) com controle de sessão.
* **Dashboard:** Indicadores rápidos de hóspedes e ocupação de quartos.
* **Hóspedes:** Cadastro, edição e exclusão de clientes (CRUD).
* **Acomodações:** Gerenciamento do catálogo de quartos e suas características (camas, suítes, ar-condicionado).
* **Check-in/Check-out:** Registro de hospedagens vinculando clientes a quartos disponíveis.

## 🛠️ Tecnologias

* **React** + **Vite** (Build e Componentização)
* **Tailwind CSS v4** (Estilização e Design System)
* **Lucide React** (Ícones)

## 🚀 Como Executar Localmente

1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2. Clone o repositório e acesse a pasta do projeto no terminal.
3. Instale as dependências:
```bash
npm install

```


4. Inicie o servidor de desenvolvimento:
```bash
npm run dev

```


5. Acesse `http://localhost:5173` no seu navegador. *(Na tela de login, basta clicar em "Entrar no Sistema").*
